# password-strength-checker
Password Strength Checker

About the Project

This is a beginner-friendly Python project that evaluates password strength using basic character variety and length checks.

Features

- Checks whether a password contains at least 8 characters.
- Checks for uppercase and lowercase letters.
- Checks for numbers and special characters.
- Classifies passwords as weak, moderate, or strong based on the number of criteria met.

Technologies Used

- Python
- GitHub

How to Run

1. Make sure Python is installed.

2. Download "main.py" and "checker.py" into the same folder.

3. Run the command:
   
   "python main.py"

4. Enter a sample password when prompted.

What I Learned

Through this project, I practised Python functions, conditional statements, loops through strings, and basic input handling.

Note

This is an educational project using simple password checks. It is not a complete security assessment tool.
